规则｜Rubric 跑分是怎么运行的？

固定课堂片段 → 两版各续写一轮 → 模型逐项判分 → 汇总对照

单轮续写 · Rubric 评测

01 / 准备同一批测试片段

固定的课堂上下文

上文师生对话 + 当前学生输入

对应教学任务 / 当前环节

同一 case，两版使用相同上文对话

不是模拟学生陪老师上完整节课

02 / 教学模型分别生成下一轮老师回复

旧版 Prompt

旧版配置 → 老师回复 A

口播 + 板书 / 组件指令

新版 V2 Prompt

新 SystemPrompt + 新任务 YAML

发言话术置空 → 老师回复 B

两版 Teaching：gemini-3.8-flash

每条 case，各生成一轮

03 / 裁判评测 = 裁判模型（JUDGE）+ 评分依据（RUBRIC）

裁判模型：deepseek-v4-pro · thinking:high

输入：课堂上下文 + 待评回复 + 对应 rubric；两版使用同一组标准

评分依据：把“好回复”拆成 9 个维度

下列为维度释义；实际按 case 选用，具体检查项 = 维度 + 级别（Must-have / Nice-to-have）+ 可判定标准

01 · 学生判断

能否识别学生的理解程度与卡点，

据此决定追问、提示还是直接讲解。

02 · 指令遵循

是否遵守教学与输出协议，

例如口播结尾、组件调用和结束标记。

03 · 数学正确性

概念、数量关系与计算是否正确，

结论是否满足题目条件。

04 · 板书质量

关键过程与关系是否同步可见，

而不是仅靠口播或遗漏关键对应。

05 · 流程执行

是否在当前环节完成应做的任务，

按条件推进、切换或结束。

06 · 答案保护

是否保留学生独立思考和作答空间，

不在需要学生尝试时提前给出答案。

07 · 讲解质量

是否讲到关键原因与易错点，

借助具体情境，把抽象关系讲明白。

08 · 讲解逻辑

推导与承接是否连贯，

前提到结论有依据，不跳步、不矛盾。

09 · 语言表达

措辞是否清楚、自然、易懂，

避免歧义与不必要的表达负担。

检查项示例：学生明确说“你继续讲”后，是否直接给出有效讲解？ → 学生判断 · Must-have

执行判分 / RUBRIC 随课堂上下文与待评回复一起交给裁判，而非独立跑一步

✓ 达标

× 不达标

— 不适用

输出每个检查项的判定和理由，供定位问题与人工复核

不是直接选“哪版更好”，而是先判断“各版是否满足具体标准”

04 / 按预设规则汇总（此处以 MUST-HAVE 否决制为例）

整条 case：有没有踩必需项红线？

任意一个 Must-have 判 × → 整条 FAIL

没有 Must-have 判 × → 整条 PASS

Nice-to-have 不决定整条通过 / 失败

整条通过率 = PASS case 数 ÷ 全部 case 数

单项 rubric：具体能力是否达标？

单项通过率 = ✓ 数 ÷（✓ 数 + × 数）

— 不适用：不计入分母

可按 Must-have / Nice-to-have、能力维度分别汇总

所以：单项通过率高，不等于整条通过率高

实验控制：比较 Prompt 时，尽量固定测试集、教学模型、采样参数、rubric 与裁判配置。

阅读边界：此图是单轮续写评测示意；判分与聚合规则应预先约定，重要结论需重复运行并人工复核。

示例｜一个 case 如何完成评测

CASE 示例 / case_001 · 不封闭图形植树 · 讲解环节

同一个课堂片段，怎样一步步判成 PASS / FAIL？

来自原评测报告；以下输入、回复与标准均为摘要，判定沿用原裁判结果，不是重新跑分。

输入：从一楼到二楼要 2 分钟，爬到四楼要多久？学生先答 8 分钟，老师已纠正为 3 段、6 分钟。

老师追问“为什么少 1”，学生沉默后说：“没事你继续讲”。另有提醒：配合动态文本板书。

旧版回复摘要

板书明确“楼层编号是点、爬楼过程是段，点数比段数多 1”。

口播解释从一楼出发，随后进入植树例题，让学生先尝试。

新版 V2 回复摘要

解释从一楼出发；板书只写“间隔”的定义，口播解释间隔。

追问“爬到 6 楼有几个间隔？”，尚未进入植树例题。

对应的 8 个检查项 → 裁判逐项判断（标准摘要）

1. 数学正确性 · Must-have

4 个楼层位置对应 3 段，段数 = 点数 − 1。

旧版 ✓ V2 ✓

2. 板书质量 · Must-have

板书同步呈现点、段及数量差异。

旧版 ✓ V2 ×：板书仅给间隔定义

3. 学生判断 · Must-have

学生表示不会 / 放弃后，直接有效讲解。

旧版 ✓ V2 ✓

4. 答案保护 · Must-have

进入例题 1 时，保留学生先作答的空间。

旧版 ✓ V2 —：尚未进入例题 1

5. 讲解质量 · Must-have

明确说明楼层位置是点、爬楼过程是段。

旧版 ✓ V2 ×：未建立点段映射

6. 讲解质量 · Must-have

口播清晰、承接自然，不连抛多个不同问题。

旧版 ✓ V2 ✓

7. 讲解质量 · Nice-to-have

学生说“继续讲”后，仍用提问引导其思考。

旧版 ✓ V2 ✓

8. 指令遵循 · Must-have

结尾提问 / 陈述与结束标记符合环节状态。

旧版 ✓ V2 ✓

整条结果：旧版 PASS；V2 FAIL。V2 有 2 项 Must-have 不达标，数学算对也不能抵消必需项失败。
