【高考考纲真题变式·例3】 难点突破

已知椭圆 \(C: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \;(a > b > 0)\) 的左右焦点分别为 \(F_1, F_2\)。若在椭圆上存在点 \(P\) 使得 \(\angle F_1 P F_2 = 60^\circ\)，且 \(\triangle F_1 P F_2\) 的面积为 \(S = \sqrt{3} b^2\)，求椭圆的离心率 \(e\) 的取值范围。

解法推导 (李老师板书) 余弦定理结合定义法

由余弦定理得：\(|F_1 F_2|^2 = |PF_1|^2 + |PF_2|^2 - 2|PF_1||PF_2| \cos 60^\circ\)

即：\(4c^2 = (|PF_1| + |PF_2|)^2 - 3|PF_1||PF_2| = 4a^2 - 3|PF_1||PF_2|\)

\(\Rightarrow |PF_1||PF_2| = \frac{4}{3}(a^2 - c^2) = \frac{4}{3}b^2\)
学员作答步骤 (张同学同步书写)
已实时同步

面积公式代入验证：

\(S_{\triangle F_1 P F_2} = \frac{1}{2} |PF_1||PF_2| \sin 60^\circ = \frac{1}{2} \cdot \left(\frac{4}{3}b^2\right) \cdot \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{3} b^2\)

check_circle 老师评语：基础扎实！结论 \(\frac{\sqrt{3}}{3}b^2 \le \sqrt{3}b^2\) 符合极大值范围！
